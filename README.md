# Long Island Dungeon Master

Source for [longislanddungeonmaster.com](https://longislanddungeonmaster.com), a site for people
who run Dungeons & Dragons games in person.

## The free tools

Three apps, all free, all built to work with the wifi off. Nothing to install, no account to make,
and nothing you write leaves the device you wrote it on.

- **[Gnasher's Grimoire](https://longislanddungeonmaster.com/grimoire)** is the Dungeon Master's
  screen. One HTML file holding your whole library: monsters, rules, NPCs, tables, maps, initiative
  and notes, searchable from anywhere in the app. Reads an Obsidian vault directly.
- **[Gnasher's Satchel](https://longislanddungeonmaster.com/satchel)** is the player's side, built
  for a phone. A 5E-compatible character sheet that rolls with one tap, tracks the fight, and links
  to the DM's screen with a short code. Reads a D&D Beyond character export or a Foundry VTT actor.
- **[Gnasher's Quill](https://longislanddungeonmaster.com/quill)** keeps session notes, recorded and
  held on your own machine.

## Free things to read and run

- **[Adventure Keepers](https://longislanddungeonmaster.com/keepers)** are a complete adventure sealed
  into a single file: the art, the read-aloud, the maps, the monsters and the secrets. Runs on its
  own in a browser, or drops into the Grimoire.
- **[VillainCraft](https://longislanddungeonmaster.com/villaincraft)** is writing on running better
  villains, including a set of pieces on Curse of Strahd.
- **[The Hoard](https://longislanddungeonmaster.com/hoard)** holds free tables, one-shots and maps.
